# Wazuh
Wazuh Security Monitoring Lab

📌 Overview

This project documents the deployment and configuration of a Wazuh security monitoring environment using an Ubuntu Server as the Wazuh Manager and a Windows endpoint as a monitored agent.

The objective of this lab is to build a small cybersecurity monitoring environment and demonstrate the collection, analysis, and detection of security events from an endpoint.

🎯 Objectives

* Deploy Wazuh on an Ubuntu Server.
* Configure a Windows endpoint as a Wazuh Agent.
* Connect the endpoint to the Wazuh Manager.
* Monitor security events generated by the Windows system.
* Analyze alerts through the Wazuh Dashboard.
* Understand the fundamentals of SIEM and endpoint security monitoring.
* Practice security event investigation and detection analysis.

🚀 Installation
1. Wazuh Manager — Ubuntu

The Wazuh Manager was installed using the official Wazuh installation script.

curl -sO https://packages.wazuh.com/4.14/wazuh-install.sh && \
sudo bash ./wazuh-install.sh -a

The -a option performs an assisted installation of the Wazuh central components.

After installation, the Wazuh Dashboard can be accessed from the server using the configured HTTPS interface.

2. Wazuh Agent — Windows

The Windows agent installer was downloaded using PowerShell:

Invoke-WebRequest -Uri https://packages.wazuh.com/4.x/windows/wazuh-agent-4.14.7-1.msi `
-OutFile $env:tmp\wazuh-agent.msi

<img width="990" height="120" alt="image" src="https://github.com/user-attachments/assets/ac04bd81-add1-4dd4-b756-32731764642a" />


The agent was then installed and configured to communicate with the Wazuh Manager:

msiexec.exe /i $env:tmp\wazuh-agent.msi /q `
WAZUH_MANAGER="<WAZUH_MANAGER_IP>" `
/l*v $env:tmp\wazuh-install.log

Replace:

<WAZUH_MANAGER_IP>

with the IP address of the Wazuh Manager.

📊 Security Monitoring

Once the Windows endpoint is connected, Wazuh can collect and analyze different types of security information.

Examples include:

* Windows authentication events
* Failed login attempts
* Successful logins
* System events
* File integrity changes
* Process and application activity
* Security-related Windows Event Logs
* Endpoint security alerts

The events can be investigated through the Wazuh Dashboard.
